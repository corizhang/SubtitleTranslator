# 后续产品能力路线图

> 更新日期：2026-08-15  
> 当前稳定能力：单视频/批量处理、项目恢复、字幕发布与命名、字幕校订、首次配置向导、轻量安装包。

## P0：批量队列可靠性增强

1. 队列项保存不可变配置快照，避免重启或全局设置变化后参数漂移。
2. 开始前逐项检查媒体、音轨、输出目录写权限、磁盘空间、模型和翻译服务。
3. 每个视频允许覆盖音轨、源语言、字幕版式和发布策略。
4. 支持重新定位移动的源视频、调整顺序、跳过、移除和清理已完成项。
5. 对网络中断、HTTP 429 和服务端错误采用可见的延迟重试策略。
6. 提供预计本地处理时间、翻译规模提示和最终队列汇总报告。

## P1：诊断与问题反馈中心

1. 汇总应用版本、GPU、Whisper runtime、模型、FFmpeg 和 DeepSeek 状态。
2. 把技术异常翻译为中文原因、影响范围和下一步操作。
3. 一键复制脱敏摘要或导出诊断包，不包含 API Key 和完整私人路径。
4. 检查项目缓存、发布记录与源文件完整性，并提供修复入口。

## P1：视频同步预览

1. 检测并选择本机 VLC，不将播放器捆绑进轻量安装包。
2. 点击字幕跳转时间，播放时高亮当前字幕。
3. 提供前后试听、毫秒级时间微调和常用快捷键。

## P2：项目与磁盘空间管理

1. 展示项目、模型、runtime 和缓存占用。
2. 按缓存类型清理，并标注是否可能再次产生 API 费用。
3. 支持保留期限、孤立项目识别和清理空间预估。

## P2：正式发布能力

1. 应用和安装包数字签名、版本检查与更新说明。
2. 配置导入/导出（不导出 API Key）。
3. 升级时保留组件路径、项目、队列和人工校订结果。
4. 建立旧版本设置与项目数据迁移测试。

## 可选增强

- ASS 字幕与样式模板、MKV 字幕封装。
- 术语表、角色名、跨集翻译记忆。
- 多翻译 Provider、硬字幕 OCR、内封字幕优先翻译。
- 多 GPU 或可控并发处理。
